# Especificaciones tecnicas

* JAVA 17 o superior.
* Spring Boot 3 o superior.
* Spring Web (Spring MVC) para exponer los controladores y sus rutas.
* Thymeleaf 3 o superior para el diseño web.
* Use Bootstrap 5 para el diseño y estilos del frontend.
* Base de datos H2 para desarrollo y pruebas.
* Consola de H2 habilitada para revisar la base de datos en desarrollo.
* Maven como herramienta de construcción.
* Spring Data JPA para la gestión de la base de datos.
* Bean Validation (Hibernate Validator) para validar los datos de entrada.
* spring-boot-starter-test (JUnit 5 y Mockito) para pruebas unitarias y de integración.
* Para las pruebas end-to-end use playwright 1 o superior.
* Servidor embebido Tomcat en el puerto 8080.
