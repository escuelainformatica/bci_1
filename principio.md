# principio

* SRP (Single Responsibility Principle)
    * Una clase debe tener una única responsabilidad o motivo para cambiar.
* KISS 
    * Keep It Simple, Stupid. Mantener las cosas simples y evitar complejidad innecesaria.
* DRY (Don't Repeat Yourself)
    * Evitar la duplicación de código, promoviendo la reutilización y la mantenibilidad.
* YAGNI (You Aren't Gonna Need It)
    * No implementar funcionalidades hasta que sean realmente necesarias.
